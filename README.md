# Purlview releases

Official builds of the `purlview` command-line tool for macOS, Linux and
Windows, on Intel and Arm.

Install instructions: <https://purlview.com/install>

Each release includes:

- archives for every platform, and `.deb` and `.rpm` packages for Linux;
- `checksums.txt` and its Sigstore bundle, `checksums.txt.sigstore.json`;
- an SPDX software bill of materials for each archive and package.

In stable releases, macOS executables are signed with an Apple Developer ID
and notarized, and Windows executables are Authenticode signed. To verify a
download, see
<https://purlview.com/install#verify>.

Releases are published by an automated workflow. This repository contains
no source code. Report security issues to <security@purlview.com>.
